# v0.5.0 更新说明

> 2026-11-22。本轮三件事：交互式图表、轻量登录权限、数据导入。功能调研依据见 `功能调研与页面规划.md`。

## 一、交互式图表（替换 matplotlib 静态图）

**问题**：原来后端生成 PNG，前端用 `<img>` 展示——不能悬停看数值、不能放大、不能下载、标签还会倾斜重叠（用户截图反馈）。

**改法**：后端不再画图，只返回结构化数据；前端用 ECharts 渲染。

| 层 | 变化 |
|---|---|
| `backend/chart_service.py`（新增） | `build_chart()` 把查询结果转成 `{type, title, labels, series, x_name, y_name}`，从问题文字自动判断柱状/折线/饼图；超过 200 行截断 |
| `backend/query_service.py` / `api.py` | 返回 `chart` 字段，去掉 `chart_path` |
| `frontend/src/components/ChartView.vue`（新增） | ECharts 渲染；柱状/折线/饼图一键切换；悬停 tooltip；图例点击隐藏系列；超过 14 个点自动出缩放条；**放大全屏弹窗**；**下载 PNG**（2 倍分辨率） |
| `frontend/src/views/Chat.vue` | `<img>` 换成 `<ChartView>` |

实测：问「核销率最高的 3 个活动」，返回 `type=bar`、标签为三个活动名、数值 `0.8154 / 0.7907 / 0.775`，前端正常渲染。

## 二、轻量登录与角色权限

**范围**：功能级权限，不是企业级 RBAC。

- `backend/auth.py`（新增）：PBKDF2-HMAC-SHA256 密码哈希（20 万次迭代，标准库无需额外依赖）、随机 Token 存 sessions 表、两种角色。
- 演示账号：`admin / admin123`（可导入数据、看全部历史）、`user / user123`（仅查询、只看自己的历史）。
- `tools.py`：`history` 表加 `username` 列（自动兼容老库），`list_history()` 按角色过滤。
- `api.py`：`/api/login`、`/api/logout`、`/api/me`、`/api/users`；所有查询接口解析 `Authorization: Bearer <token>`。
- `frontend/src/auth.js`（新增）：Token 存 localStorage；`frontend/src/views/Login.vue`（新增）；`App.vue` 加登录门、顶栏用户 chip 和退出按钮。
- 文件下载加了路径校验，只允许下载 output 目录内文件，防止路径穿越。

**实测**：admin 登录成功、普通用户调用导入接口返回 **HTTP 403**。

## 三、数据导入（Excel / CSV → 数据库）

**边界**：只做结构化表格，不做 PDF/Word 向量化（那是另一个项目，跑题）。

- `backend/import_service.py`（新增）：pandas 解析 CSV/Excel（自动试 UTF-8/GBK 编码）→ 预览前 5 行 → 白名单校验 → 只 INSERT 到已有业务表 → 刷新表规模。
  - 安全默认（照搬 JimuReport）：`ALLOWED_TABLES` 白名单 7 张表，不接受用户传来的 DDL/DML，不允许新建表结构，主键列由数据库管理。
  - 导入留痕写入 `import_history` 表。
- `api.py`：`/api/tables`、`/api/import/preview`、`/api/import/commit`（仅 admin）、`/api/import/history`。
- `frontend/src/views/DataImport.vue`（新增）：三步向导（选择文件 → 预览字段 → 确认入库），左侧菜单新增「数据导入」。
- `Dashboard.vue`：概览页新增「数据源」区块，实时显示 8 张表的行数与字段数。

**实测**：上传 2 行测试 CSV → 预览正确 → admin 确认入库后 customers 600→602 行；普通用户越权被拒；测试数据已清理，行数恢复 600。

## 六、已知取舍

- ECharts 打进主 bundle，构建产物约 2.3MB（gzip 780KB），本地演示无影响；真要优化可做动态 import，但毕设不必要。
- 登录用随机 Token 存 SQLite，没有 JWT 签名和过期机制——功能演示够用，写进局限性。
- 数据导入只追加、不覆盖、不删行——这是有意为之的安全默认。
