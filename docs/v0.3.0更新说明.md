真实业务特征：
- **季节性**：11–12 月旺季（月均 1200 单），1–2 月春节低谷（约 500 单）

## 三、后端分层重构

拆成 5 层，`agent.py` 从 148 行变成 6 行兼容层：

```
schemas.py       Pydantic 请求/响应模型，统一接口契约
llm_client.py    只管调 DeepSeek，构造提示词
sql_service.py   生成 SQL、纠错循环、错误分类、失败建议
query_service.py 编排：查询 + 统计 + 图表 + 导出 + 留痕
api.py           只做路由，不含业务逻辑
agent.py         兼容层（评测脚本仍可用旧接口）
```

对外接口与行为完全不变，30 题评测仍 30/30。
